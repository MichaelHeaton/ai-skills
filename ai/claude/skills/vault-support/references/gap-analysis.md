# Gap analysis format

## Team questions format (TEAM-QUESTIONS.md entry)

Write questions as a Sr SRE would — share what you already researched and propose an answer for the team to validate. Append entries to `TEAM-QUESTIONS.md` in the work docs repo:

```
### [Descriptive title]
*Source: [link to test case file]*

**Question:** [The specific thing only team knowledge can confirm]

**Our research:** [What you found — which docs/files, what they say, key gaps]

**Proposed answer:** [Your best draft answer based on docs + expertise]

**the support bot improvement path:** [Specific file to update and what to add/change. Include `sherlock: true` tagging if needed.]

**work customer skills repo coverage:** [Covered in `<topic-file>.md` / Gap — needs update / New topic file needed]
```

Group items under relevant section headings. The user will bring the full list to the team at once.
