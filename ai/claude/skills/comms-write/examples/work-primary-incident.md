# [work-primary] — Incident report (public stub)

Post-incident or operational event summary for **work-primary** context.

**Audience:** Leadership, affected teams, on-call  
**Tone:** Factual, no blame; focus on impact, timeline, and follow-up

## What to gather

- Summary, impact, timeline, root cause, immediate fix, follow-up actions, ticket reference

## Format

```
**Incident: [short title]**

**Impact:** [who/what, duration]
**Timeline:** [detect → mitigate → resolve]
**Root cause:** [one paragraph]
**Resolution:** [what fixed it]
**Follow-up:** [actions + ticket links]
```

Use private Memex examples for employer-specific severity and channel norms.
