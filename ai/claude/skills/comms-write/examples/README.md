# Comms-write examples (public stubs)

These files are **generic templates** safe for the public repo. They define structure only.

**Full examples** (domain-specific tone, Jira/Slack hints) live in your **private personal KB** repo:

`ai/claude/skills/comms-write-context/examples/`

Configure `comms_write.examples_root` in `~/.config/ai-skills/local.json` (see ai-skills `docs/guides/local-config.md`).

When the vault is the project cwd, `comms-write` resolves examples from that tracked path automatically.
