# Comms-write examples (public stubs)

These files are **generic templates** safe for the public repo. They define structure only.

**Full examples** (domain-specific tone, Jira/Slack hints) live in your **private Memex** repo:

`memex/.claude/skills/comms-write-context/examples/`

Configure `comms_write.examples_root` in `~/.config/ai-skills/local.json` (see [docs/guides/local-config.md](../../../../docs/guides/local-config.md)).

When the Memex vault is the project cwd, `comms-write` resolves examples from that path automatically.
