# Ultraviolet Cyber (UV) — Internal Communications

General-purpose guide for writing internal comms at Ultraviolet Cyber.

## Before writing

Ask the user:
1. **Who is the audience?** (team, leadership, cross-functional, all-hands)
2. **What is the purpose?** (status update, decision, announcement, escalation, FYI)
3. **What channel/format?** (Slack, email, doc, meeting follow-up)
4. **Any specific format or template UV uses for this type of message?**

If the user has a preferred format or past examples, ask them to share one — UV's internal style should guide the output, not be imposed from outside.

## General principles

- Lead with the most important information
- State the ask or action item explicitly and early if there is one
- Match length to urgency: a quick FYI is 2–3 sentences; a project update can be longer
- Use bullet points for lists of facts; prose for context and reasoning
- Close with a clear next step or "no action needed"

## Common types

**Status update**
```
**[Project/Initiative] — [Date]**
Status: [On track / At risk / Blocked]

[2–3 sentence summary]

Progress: [what's done]
Next: [what's coming]
Blockers: [anything stuck] — [ask if needed]
```

**Announcement**
```
[What's changing and when]
[Why it matters / who is affected]
[What people need to do, if anything]
[Where to ask questions]
```

**Escalation / ask**
```
[1-sentence context]
[Specific ask — decision, resource, unblocking]
[Deadline or urgency]
[Impact of not acting]
```
