Skill naming prefix conventions are defined in [CONVENTIONS.md](../CONVENTIONS.md) under "Domain prefixes".

When suggesting a name for a new skill, consult that table to pick the right prefix for the domain the skill serves.

**VCS routing:**
- GitHub: Adobe work + personal repos
- GitLab: personal projects
- Cross-platform skills use `issue-` or `pr-` prefix (no platform suffix)
